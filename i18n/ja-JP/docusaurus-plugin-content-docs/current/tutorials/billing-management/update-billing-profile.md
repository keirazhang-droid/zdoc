# 請求プロファイルの更新

請求プロファイルには、請求、請求書、税務記録に使用する組織情報と連絡先情報が含まれます。請求プロファイルを最新の状態に保つことで、請求書が正しい会社、住所、連絡先詳細で発行されます。請求プロファイルの詳細については、[請求書について](./view-invoice#billing-profile) を参照してください。

<Admonition type="info" icon="📘" title="**Note**">

請求プロファイルを管理するには、**組織オーナー** または **組織の請求管理者** である必要があります。

</Admonition>

## 請求プロファイルの更新\{#update-billing-profile}

![OyU3wocxShpyvAb18M6c7ymHnkF](https://zdoc-images.s3.us-west-2.amazonaws.com/OyU3wocxShpyvAb18M6c7ymHnkF.png)

<Procedures>

1. Zilliz Cloud コンソールで、**請求** に移動します。

1. **請求プロファイル** セクションで **編集** をクリックします。

1. 必要な請求情報を更新します。**確認** をクリックします。

</Procedures>

## 請求プロファイルの更新後\{#after-you-update-the-billing-profile}

請求プロファイルが更新されると、今後の請求書は新しい請求情報を使用します。

以前に発行された請求書は変更されません。既存の請求書の情報を更新する必要がある場合は、finance@zilliz.com の Zilliz Finance チームにお問い合わせください。
