# ストレージコスト

Zilliz Cloud では、クラスターが実行中かどうかに関わらず、データまたはバックアップファイルを保存するとストレージコストが発生します。

## ストレージコストの発生源\{#sources-of-storage-costs}

以下のシナリオでストレージの課金が発生します:

- Dedicated クラスター: Dedicated クラスターに保存されたデータ。

- Serverless クラスター: Serverless クラスターに保存されたデータ。

- [データベース](./on-demand-database): オンデマンド検索に使用するデータベースに保存されたデータ。

    - マネージドコレクション内のデータおよびインデックス。

    - 外部コレクション内のインデックス。

- [バックアップ](./backup-and-restore) ストレージ: ディザスタリカバリ用に作成したバックアップファイル。

- [マネージドボリューム](./managed-volume) ストレージ: ボリュームに保存された構造化データまたは非構造化データファイルのコレクション。

## コスト計算\{#cost-calculation}

```plaintext
Storage Cost = Storage Unit Price x Data Size x Duration
```

- ストレージ単価: クラウドリージョンとクラスタータイプによって決定されます。詳細な料金については、[Zilliz Cloud 料金](https://zilliz.com/pricing) を参照してください。

- データサイズ: Zilliz Cloud に保存されているすべてのデータのサイズ、またはバックアップファイルのサイズで、GB単位で測定されます。

- 期間: Zilliz Cloud にデータまたはバックアップファイルが保存されている時間の長さ。

## 請求ルール\{#billing-rules}

クラスター、ボリュームストレージの請求ルールは、バックアップストレージおよびコールドデータアクセスとは若干異なります。

- **専用 & サーバーレスクラスター、ボリューム、およびデータベースストレージ:** 時間単位で請求され、最低料金は1時間です。

- **バックアップストレージ:** 日単位で請求され、最低料金は1日です。

## 例\{#examples}

ストレージ費用の計算方法を理解するための例をいくつか示します。

### 例1: 専用クラスターのストレージ費用\{#example-1-dedicated-cluster-storage-cost}

サービングクラスターの構成が以下の通りと仮定します:

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: パフォーマンス最適化済み

- **データサイズ**: 500 GB

- **ストレージ期間**: 29日23時間30分

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ページ](https://zilliz.com/pricing) でストレージ単価が **&#36;0.025/GB 月あたり** であることが確認できます。

[請求ルール](./storage-cost#billing-rules) により、1時間未満の端数は1時間に切り上げられます。ストレージ期間の29日23時間30分は30日、つまり1ヶ月に切り上げられます。

データストレージの総費用は `$0.025 x 500 × 1 = $12.50` となります。

### 例2: バックアップストレージ費用\{#example-2-backup-storage-cost}

クラスターの構成が以下の通りと仮定します:

- **クラウドプロバイダーとリージョン**: AWS us-east-1 (バージニア)

- **クラスタータイプ**: パフォーマンス最適化済み

- **バックアップファイルサイズ**: 20 GB

- **バックアップファイル保持期間**: 44日6時間

クラウドプロバイダーとリージョン、およびクラスタータイプの情報から、[料金ページ](https://zilliz.com/pricing) でストレージ単価が **&#36;0.025/GB 月あたり** であることが確認できます。

[請求ルール](./storage-cost#billing-rules) により、1日未満の端数は1日に切り上げられます。そのため、保持期間の44日6時間は45日、つまり1.5ヶ月に切り上げられます。

この例のクラスターのバックアップストレージ総費用は `$0.025 x 20 x 1.5 = $0.75` となります。

### 例3: マネージドボリュームストレージ費用\{#example-3-managed-volume-storage-cost}

ボリュームに **10 GB** のデータをアップロードしてインポートし、**1ヶ月間** 保持する場合、単価が **&#36;0.04/GB 月あたり** であれば、費用は `$0.04 × 10 × 1 = $0.40` となります。

## よくある質問\{#faqs}

1. **クラスターを停止してもストレージ料金は発生しますか?**

    はい。クラスターが停止中であっても、クラスターデータ、バックアップ、またはボリュームファイルが保持されている限り、ストレージ費用が適用されます。

1. **ストレージに最低料金はありますか?**
 はい。ストレージには最低料金があります。

    - クラスターおよびボリュームストレージ: 最低1時間の料金。

    - バックアップストレージ: 最低1日の料金。
