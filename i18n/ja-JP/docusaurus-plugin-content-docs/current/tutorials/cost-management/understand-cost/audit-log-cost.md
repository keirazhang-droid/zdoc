# 監査ログのコスト

監査ログを有効にすると、Zilliz Cloud はログ記録サービスをデプロイします。これらのログの収集、処理、転送には追加のシステムリソースが消費されるため、対応する料金が発生します。

監査ログ機能を使用する総コストは、以下の要素の合計です。

- [監査ログ CU コスト](./audit-log-cost#audit-logs-cu-cost): 監査ログの収集と処理によって消費されるコンピュータリソースのコスト

- [データ転送コスト](./audit-log-cost#data-transfer-cost): ログをオブジェクトストレージに転送するコスト

## 監査ログ CU コスト\{#audit-logs-cu-cost}

```plaintext
Audit Logs CU Cost = Audit Logs CU Unit Price x Total Number of Query CU x Audit Logs Runtime
```

- **監査ログ CU 単価**: クラスターリージョンとプロジェクトプランによって決定されます。詳細な料金については、[Zilliz Cloud 価格ガイド](https://zilliz.com/pricing/pricing-guide) を参照してください。

- **クエリCU総数**: レプリカを含む、クラスター内のクエリCUの総数です。

    ```plaintext
    Total Number of Query CU = Query CU × Replica Count
    ```

    たとえば、2つのクエリCUと2つのレプリカを持つクラスターは、合計4CUになります。

- **監査ログ実行時間**: 監査ログ機能が有効になっている合計時間。実行時間は `無効化時点 − 有効化時点` として計算されます。クラスターが**一時停止**ステータスにある場合、または監査ログ機能が**異常**ステータスにある場合、その時間は計算から除外されます。これは、一時停止中に監査ログ機能がコンピューティングリソースを消費しないためです。実行時間の計算例については、[例](./audit-log-cost#example) を参照してください。

## データ転送コスト\{#data-transfer-cost}

監査ログはオブジェクトストレージバケットに転送できます。現在、Zilliz Cloudは、クラスターと同じクラウドリージョンに作成されたオブジェクトストレージバケットへのログ転送のみをサポートしています。

リージョン内のデータ転送は現在追加料金が発生しません。

データ転送の料金の詳細については、[データ転送](./data-transfer-cost) を参照してください。

## 例\{#example}

クラスター構成が次のとおりであるとします。

- **プロジェクトプラン:** Enterprise

- **クラスターデプロイオプション**: Dedicated

- **クラウドプロバイダーとリージョン:** AWS us-east-1 (バージニア)

- **CUサイズ:** 8 CU

- **レプリカ数:** 2

- **監査ログ実行時間:** 

    ![JKGIwkjiyhRr2ebq4eKcUsZOn8d](https://zdoc-images.s3.us-west-2.amazonaws.com/JKGIwkjiyhRr2ebq4eKcUsZOn8d.png)

    上図のように、

    - 監査ログは2025年8月1日12:00に有効化されました。

    - クラスターは2025年8月1日24:00に一時停止されました。

    - クラスターは2025年8月2日12:00に再開され、2025年8月3日12:00に削除されるまで実行されました。

    合計実行時間は `(24 − 12) + 24 = 36 時間` です。

プロジェクトプランとクラウドプロバイダーおよびリージョンの情報をもとに、[料金ガイドページ](https://zilliz.com/pricing/pricing-guide) で監査ログの単価が **&#36;0.031/時間** であることがわかります。

CUサイズとレプリカ数の情報から、クエリCUの合計サイズは `8 CU x 2 レプリカ = 16 CU` です。

監査ログCUの合計コストは `$0.031 x 16 x 36 = $17.856` です。

データ転送コストは同リージョン転送のため **&#36;0** です。

監査ログの合計コストは `$17.856 + $0.00 = $17.856` です。

## よくある質問\{#faqs}

1. **クラスターが一時停止されている場合、監査ログの料金は発生しますか？**
いいえ。監査ログCUの料金は、機能が有効でクラスターがアクティブに実行されている間のみ適用されます。「一時停止」状態の時間は除外されます。

1. **監査ログを転送する際にデータ転送の料金は発生しますか？**
リージョン内の転送は無料です。クロスリージョン転送（現在はサポートされていません）は追加料金が発生する可能性があります。

1. **監査ログが有効になっているが、実際にログが生成されない場合でも料金は発生しますか？**
はい。監査ログCUの料金は、ログが生成されるかどうかに関係なく、機能が有効な間のクラスターのクエリCUサイズと実行時間に基づきます。ログが生成されない場合、データ転送コストは&#36;0になる可能性があります。

1. **生成されるログの実際の量（例：高QPSと低QPSのワークロード）によって課金は変わりますか？**
いいえ。監査ログCUのコストは、クラスターのクエリCUサイズと実行時間のみに依存し、生成されるログの量には依存しません。
