# クレジット

クレジットは、Zilliz Cloud の使用料金に充当できます。仕事用メールで Zilliz Cloud に登録した場合、対象となる Zilliz Cloud プログラムやイベントに参加した場合、または Zilliz から概念実証 (PoC) のクレジットを受け取った場合に、クレジットを受け取ることができます。

クレジットを利用すると、長期的な支払い方法を設定する前に、Zilliz Cloud を試したり、評価ワークロードを実行したりできます。

<Admonition type="info" icon="📘" title="Note">

クレジットと支払い方法を管理するには、**組織オーナー**または**組織の請求管理者**である必要があります。

</Admonition>

## クレジットの仕組み\{#how-credits-work}

クレジットは、他の[支払い方法](./payment-billing#payment-methods)よりも先に、使用料金に自動的に適用されます。

複数の支払い方法や残高が利用可能な場合、Zilliz Cloud は以下の順序で適用します。

1. クレジット

1. 前払い残高

1. マーケットプレイスサブスクリプション

## クレジットの有効期限\{#credit-validity}

クレジットには有効期限があります。期限が切れたクレジットは、将来の使用料金に使用できません。

利用可能なクレジットを失わないようにするには、次の点に注意してください。

- 残クレジット残高を定期的に確認する。

- クレジットの有効期限までの残り日数を確認する。

- 期限が切れる前にクレジットを使用する。

- 有効な支払い方法を追加して、クレジットの有効期限を30日から1年に延長する。

- クレジットの有効期限に関する質問がある場合は、[Zilliz Support](http://support.zilliz.com)またはアカウントエグゼクティブに問い合わせる。

## クレジットと支払い方法\{#credits-and-payment-methods}

クレジットは、前払い残高またはマーケットプレイスサブスクリプションのいずれかと併用できます。

ただし、クレジットは長期的な支払い方法の代わりにはなりません。クレジットがなくなったり期限が切れたりして、他に有効な支払い方法がない場合、組織は高度な機能にアクセスできなくなり、凍結されます。

クレジット使用後も Zilliz Cloud を継続して使用するには、次のいずれかの支払い方法を設定してください。

- [前払い](./advance-pay)

- [AWS マーケットプレイスサブスクリプション](./subscribe-on-aws-marketplace)

## クレジットの申請\{#apply-for-credits}

PoC 用にさらにクレジットが必要な場合は、[セールスにお問い合わせ](http://zilliz.com/contact-sales)いただくか、アカウントエグゼクティブにご連絡ください。
