# 前払い

Zilliz Cloud は、クレジットカードの追加や AWS Marketplace でのサブスクリプションに代わる支払い方法として、前払い（銀行振込）を受け付けています。

<Admonition type="info" icon="📘" title="Note">

支払い方法を管理するには、**組織オーナー** または **組織の請求管理者** である必要があります。

</Admonition>

## 前払いへの資金追加\{#add-funds-to-advance-pay}

現在、前払い残高に資金を追加するには、[お問い合わせ](https://zilliz.com/contact-sales) のみ可能です。

## 前払い履歴の表示\{#view-advance-pay-history}

銀行振込履歴を表示するには、上部のナビゲーションバーまたは左側のナビゲーションペインで **[請求]** をクリックします。次に、**[前払い]** セクションの **[履歴]** をクリックします。[**銀行振込履歴**] ページでは、振込を行った時間、追加した資金の金額など、過去のすべての振込の詳細を確認できます。

![add-fund-en](https://zdoc-images.s3.us-west-2.amazonaws.com/add-fund-en.png "add-fund-en")

## 前払い残高のモニター設定\{#set-monitor-for-advance-pay-balance}

デフォルトでは、前払い残高のモニタリングは無効になっています。ただし、モニタリングを有効にすると、前払い残高がモニタリング条件で指定した金額未満になった場合に通知を受け取ることができます。詳細については、[組織アラートの管理](./manage-organization-alerts) を参照してください。

## 前払い資金の返金\{#refund-advance-pay-funds}

現在、Zilliz Cloud は Web コンソールでの返金をサポートしていません。返金を希望される場合は、Zilliz Cloud [サポートポータル](https://support.zilliz.com/hc/en-us) からお問い合わせの上、リクエストを送信してください。
